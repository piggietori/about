📷 Photo Memory Search Search Index Photos Setup

Setup

Configure where your iPhone photos are stored and verify your Anthropic API key.

1. Anthropic API Key

Set ANTHROPIC_API_KEY in your .env file and restart the server.

2. iPhone Photo Folder

Enter the full path to the folder containing your iPhone photos.

How to get iPhone photos onto your computer ▾
macOS: Connect your iPhone via USB → unlock your phone → open Image Capture (Cmd+Space → type "Image Capture") → select your iPhone in the sidebar → choose an Import To folder → click "Import All". Photos export as original files (HEIC/JPEG) with all metadata intact.

Windows: Connect iPhone via USB → unlock your phone and tap "Trust This Computer" → open File Explorer → your iPhone appears under "This PC" → navigate to Internal Storage › DCIM → copy the folders to a local path like C:\Users\You\Pictures\iPhone.

Linux: Install libimobiledevice and ifuse, then: idevicepair pair && mkdir ~/iphone && ifuse ~/iphone && cp -r ~/iphone/DCIM ~/Pictures/iPhone && fusermount -u ~/iphone
